# Quiz review pack

Real human quiz cases are not yet labeled, so no quiz questions or scores are included here. This prevents synthetic predictions from becoming ground truth.

When `evals/real/quiz_cases.csv` has human-reviewed cases, each review item should contain:

- Quiz ID and lesson
- Concept and requested difficulty
- Question and options
- Correct answer and explanation
- Citation/source excerpt
- Page or timestamp

The generated pack must be reviewed by lecturers/students using `quiz_review_template.csv`.
